## OpenAI Codex open source fund (upstream announcement)

This is an OpenAI announcement about its **$1 million initiative** supporting open source projects that use OpenAI Codex CLI and other OpenAI models. It is an upstream program, not a Web2Codex feature.

- Grants are awarded up to **$25,000** API credits.
- Applications are reviewed **on a rolling basis**.
